# PayPerUseAPI – Usage-Based API Access Contract
PayPerUseAPI allows developers to monetize API services by charging users per call.
Users pre-fund balances and get charged automatically when they access a paid endpoint.

## Core Capabilities
- Register metered API services with per-use pricing
- Pre-funded user balances for instant authorization
- Automatic cost deduction on API call validation
- Provider withdrawal of earned STX

## Key Functions
register-service, deposit, authorize-call, withdraw, get-service-info, get-user-balance
